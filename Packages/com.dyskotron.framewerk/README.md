# Framewerk

Inversion of control MVCS micro-framework with dependency injection for Unity, built on StrangeIoC.

## Installation

Add to your Unity project via the Package Manager using the git URL:

```
https://github.com/dyskotron/Framewerk.git?path=Packages/com.dyskotron.framewerk
```

Or add directly to `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.dyskotron.framewerk": "https://github.com/dyskotron/Framewerk.git?path=Packages/com.dyskotron.framewerk"
  }
}
```

## Requirements

- Unity 2021.3 or later
